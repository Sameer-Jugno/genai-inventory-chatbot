F) DATA PATH (how a file becomes queryable)
-------------------------------------------
  Local sample file
    → aws s3 cp … s3://inventory-planner-dev-data-…/uploads/<vendor>/<file>
    → S3 event triggers Lambda inventory-planner-dev-ingestion
    → parse (csv/xlsx/txt/pdf) → optional image store under images/
    → embed (Hugging Face bge-large) → upsert OpenSearch Serverless
    → Chat searches OpenSearch and returns grounded cards
